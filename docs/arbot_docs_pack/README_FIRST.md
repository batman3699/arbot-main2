- arbot_env_ethereum.env

## Quick start

1. Read `arbot_docs_index.md`
2. Pick the chain you want to work on
3. Copy the matching env template to `.env`
4. Fill in the blank values
5. Run the health checks from `arbot_master_runbook.md`
6. Use fork testing and shadow mode before trusting live execution
